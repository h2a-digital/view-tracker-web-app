# Zernio free allowance: implementation decision

**Update November 9, 2026:** the optional [Instagram/Zernio pilot](zernio-instagram.md) now supports one TikTok plus one Instagram account within these two slots. It defaults off. The original TikTok-only implementation decision below is retained as historical verification context.

Documentation checked November 7, 2026. This is a **documentation-backed integration**, not a live-account entitlement test. No Zernio account/key or connected creator was available.

| Requirement                            | Documented capability / implementation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Free analytics API                     | Current pricing says first two connected accounts are free, no credit card, every feature included. Analytics API explicitly distinguishes current usage-based access from legacy plans requiring an add-on. A `402` stops collection and flags the account; no upgrade is attempted.                                                                                                                                                                                                                                       |
| Discover posts published inside TikTok | `POST https://zernio.com/api/v1/posts/sync-external` with `{accountId}` and no `url`/`postId` refreshes and returns recent external posts. TikTok is explicitly supported. This does not require posting through Zernio.                                                                                                                                                                                                                                                                                                    |
| Read public counters                   | `GET /v1/analytics?accountId=…&platform=tiktok&source=all&fromDate=…&limit=100&page=…`. List responses contain `posts[].platforms[].platformPostId` and per-platform `analytics.views`; `pagination.pages` controls traversal. The platform native ID is not Zernio's internal `_id`.                                                                                                                                                                                                                                       |
| Catch missed videos                    | Paginate analytics history in addition to recent external discovery. Maximum API date range is 366 days; this implementation reads 365 days, with a bounded request budget. History and media omissions still need verification on a real account.                                                                                                                                                                                                                                                                          |
| Creator consent                        | `GET /v1/connect/tiktok?profileId=…&redirect_url=…&scopes=analytics&expectedUsername=…`. API key belongs on server. The creator authorizes Zernio's own TikTok app. TikTok now uses Zernio's TikTok for Business connection product; required consent/account eligibility must be checked during onboarding. No separately approved developer app is assumed.                                                                                                                                                               |
| Disconnect                             | `DELETE /v1/accounts/{id}`. Documented one-hour restoration grace period; reconnecting the same account during it restores its ID/history. Provider deletes it permanently afterward. Our local accounting history is separate and subject to applicable retention terms.                                                                                                                                                                                                                                                   |
| Replace connected accounts             | Pricing is connected-account usage, not a lifetime allotment of two identities; disconnecting is supported. No separate swap/connection fee is documented. **The docs do not give an unconditional guarantee that arbitrary same-day swaps never incur billable usage.** Keep no card on file, disconnect first, wait for the provider to release the slot if necessary, check its connection/usage page, and obtain provider confirmation if a gate appears. Never authorize a third concurrent account or a paid upgrade. |
| Organic-only and fraud exclusion       | A public `views` count does not prove organic traffic or exclude artificial views. The adapter always labels it unverified. Zernio's optional authenticity products are not used as proof of payout eligibility. Evidence review remains required.                                                                                                                                                                                                                                                                          |
| Exact first-seven-day views            | Hourly attempts reduce gaps but cached observations do not establish an exact 168-hour total. Provider freshness is retained when returned. Exact-window/organic evidence must be reviewed. No interpolation is silently used for payment.                                                                                                                                                                                                                                                                                  |

The two free slots cover the entire Zernio workspace across networks, not two TikTok accounts plus free Instagram/YouTube/Facebook connections. Prefer two TikTok pilot accounts; other networks can be added through separate official adapters later. The dashboard checks the provider's team account list, reserves pending links, binds authorization to the expected username, and never calls billing, publishing or ads endpoints. Other software or manual activity in Zernio can bypass local limits, so the no-card restriction matters.

OAuth `scopes=analytics` narrows requested areas but does **not** make TikTok's grant read-only. The current connect specification lists `video.publish`, `video.upload`, and `video.list` among always-requested TikTok scopes, alongside identity scopes. Analytics adds `user.info.stats`, `user.insights`, `video.list`, `video.insights`. Explain that consent to the creator; this app never publishes content.

Documented free request rate: 60 requests/minute; analytics also has a 6 requests/second burst window. Analytics may be cached for roughly an hour; background external discovery can take roughly 90 minutes. Some richer insights have 24–48 hour lag. Public counter snapshots are observations of provider-reported data, not live exact TikTok UI readings.

## Required live pilot before relying on payouts

1. Confirm the new no-card workspace can call external sync and analytics without a 402/add-on gate.
2. Authorize the intended account and check the actual consent/account requirements.
3. Publish directly in TikTok; compare discovered native ID, timestamp, media type, and view count.
4. Compare a later changed counter and cached-counter freshness; test an expired grant and reconnection.
5. Disconnect a test account, confirm slot release/usage, and connect its replacement without billing or a card prompt. If unclear, ask Zernio support about same-day account-day accounting.
6. Check creator consent, contractual retention and account deletion requirements before production data collection.

Until this passes, the UI accurately calls this a TikTok pilot and retains CSV as a temporary fallback. Do not upgrade automatically if any step fails.
